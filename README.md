# 最近妻が冷たくてさあ

▶ **遊ぶ：https://katomi95.github.io/tsuma-ga-tsumetai/**

同僚の、ただの夫婦の愚痴。

職場の同僚・沢口さんから「最近妻が冷たくてさあ」と相談される。
返事をしない、飯を食わない、ずっと同じ場所にいる──
どこにでもある倦怠期の話を、数日にわたって聞き流していく短編会話ノベル。

- プレイ時間：約3〜5分
- 操作：マウス（クリック）のみ／スマホのタップでも可
- 各日に1回、返事の温度感（相槌・心配・冗談）を選べます。結末は変わりません
- 右上の「履歴」でそれまでの会話を読み返せます

## 技術
- HTML / CSS / JavaScript のみ（外部ライブラリなし）
- 静的ホスティング（GitHub Pages）で動作
- 画像は同一背景をズーム・パンして場面ごとの構図を変えています

## 素材
- `assets/images/` の画像はすべて画像生成AI（OpenAI の画像モデル）で本作用に生成したものです
- アートディレクションと生成方針：[`assets/art_direction.md`](assets/art_direction.md)

## ファイル構成
```
index.html   画面構成
style.css    見た目
game.js      台本と進行
assets/images/        背景画像
assets/art_direction.md
```
